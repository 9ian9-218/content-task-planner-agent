## 4. 测试是否足够

对本 MVP 已声明的本地、确定性工具范围，关键正常/失败/状态交叉已比初轮充分：不只测串行成功，还覆盖配置毒化、批量动作、错误协议、生成后网络失败、保存事务与最终快照两个不同失败阶段，以及集合身份和版本漂移。

这不是“证明没有隐藏问题”。已补真实 API 行为与有限选择路径；长期模型稳定性、真实外部计费/对账仍缺；不承诺分布式 exactly-once、任意旧数据库格式迁移、强杀后的自动接管或严格实时抢占。这些均不能由离线测试通过率补足。

180 秒只控制新动作派发；本地提交或网络等待已经发生时不强制终止进程。若实际保存成功但耗时超限，返回 saved 事实并显式标记超限。硬性的调用次数上限仍在每个动作前执行。
